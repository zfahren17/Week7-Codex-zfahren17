# Reflection of Codex Hands-On Experience

I was pleasantly surprised at how easy and efficient this Codex experience was to set-up and leverage to analyze this AmesHousing data set.
I don't have a ton of experience working within a terminal window but once I got through the intimidating parts it was quite intuitive and easy to work in.
This hands-on analysis mini-project was also another great learning experience to get more comfortable with the different components of GitHub.
I felt like it all went together pretty smoothly and the integration was cohesive.

Codex, for the most part, did not really struggle.  
There were a couple of times where folder structure was causing a bit of an issue but eventually, after some clearer and more explicit instructions it was able to figure out where I wanted the outputs to actually go.
Other than that, I found the whole analysis experience quite enjoyable.
Codex offered suggestions along the way of things I had not thought of but then I was able to build off of their recommendations for an even better and more refined analysis.
I felt it was a healthy back-and-forth discussion and learning process.
One other thing I would note is that /transcript was not a viable command for me to use within Codex.
It took a little bit of research and troubleshooting to find the command /export, which I believe is similar to what /transcript would have produced.

Overall, I was very impressed with the output tables, summary statistics, and charts Codex was able to produce.  
I think I could have been a little more succinct with my prompts but at the same time I was exploring the data set for the first time and learning as I went along.
If I was more familiar with the data set I could certainly see myself using more detailed, complex prompts to accomplish what I need.
Regardless, I definitely feel more confident in Codex's abilities to produce accurate and solid work products.

In retrospect, I really should have built in an ai-workflow-log tracker into the beginning of my Codex session.
Like if I say "track this", load this next prompt into the ai-workflow-log markdown file and populate some of the required details of the assignment.
Having to do that all semi-manually during the analysis was quite tedious.
That is definitely a suggestion I will bring to my team when we start leveraging AI-generated analytics in our projects.
